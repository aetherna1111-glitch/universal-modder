FarCryCoop 0.2.0 — экспериментальный кооператив для Far Cry (2004), патч 1.4
==============================================================================

ВАЖНО: мод собран и проверен вне игры (под Wine), но в настоящем Far Cry ещё не запускался.
Ты будешь первым, кто его проверит. Если что-то сломается — пришли последние строки из log.txt.

Что нужно
---------
- Far Cry с патчем 1.4 (версии Steam и GOG подходят). Только 32-битная игра (папка Bin32).
- У всех игроков должен быть один и тот же FarCryCoop.exe (лаунчер показывает номер сборки — он должен
  совпадать).

Установка
---------
1. Распакуй архив куда угодно. Достаточно одного файла FarCryCoop.exe — весь мод зашит внутрь.
2. Запусти FarCryCoop.exe. Если игра не нашлась сама, нажми "Browse..." и выбери папку, где лежит
   Bin32\FarCry.exe.
3. Нажми "Install / update mod". Мод копируется в <Far Cry>\Mods\FarCryCoop. Старая версия мода, если была,
   переименовывается в FarCryCoop.backup-<дата>. Оригинальные файлы игры не меняются.
   Удалить мод = удалить папку Mods\FarCryCoop.

Создать игру (хост)
-------------------
1. Выбери карту (Map) — это папки из <Far Cry>\Levels. Миссию можно не указывать.
2. Укажи название сервера, число игроков (2–16), порт (по умолчанию 49001), пароль — по желанию.
3. Нажми "Host". Far Cry запустится и загрузит уровень как кооп-сервер.
4. Для игры через интернет открой/пробрось порт UDP 49001 на ПК хоста (через интернет не проверялось).

Подключиться
------------
1. Нажми "Find LAN games" и выбери игру из списка, или введи IP хоста.
2. Нажми "Join". Far Cry запустится и подключится. Удалось ли подключение — видно только в самой игре.

Без лаунчера (из папки Bin32):
  хост:   FarCry.exe -MOD:FarCryCoop -coophost:<уровень>
  клиент: FarCry.exe -MOD:FarCryCoop -coopjoin:<IP хоста>

В игре
------
Консоль: клавиша ~
  coop_status            — состояние кооп-сессии (роль, игроки, ИИ, точка возрождения)
  coop_friendlyfire 1    — включить урон по своим (по умолчанию выключен)
  coop_respawn_delay 5   — через сколько секунд можно возродиться (выстрел = возродиться)
  coop_auto_respawn 20   — автоматическое возрождение через N секунд (0 = выкл.)
  coop_debug 1           — подробный лог
Все сообщения мода пишутся в log.txt в папке Far Cry со словом [coop].

Как это работает
----------------
- Хост — это сервер: только он считает ИИ врагов, а клиентам рассылает их движение, стрельбу и смерти.
- Каждому игроку создаётся свой персонаж с оружием миссии. Враги видят и атакуют всех игроков.
- Чекпоинт кампании не сохраняет игру, а переносит общую точку возрождения.
- Переход на следующий уровень делается на сервере, клиенты остаются подключёнными (новое, не проверено).

Известные ограничения
---------------------
- Ничего не проверено в настоящей игре.
- Некоторые скриптовые события миссий могут срабатывать только на хоста (в скриптах кампании "игрок" —
  это хост). Катсцены и сообщения HUD от сервера видит только хост.
- Сохранение игры в мультиплеере отключено самим движком.
- Оружие между уровнями не переносится.

Если не работает
----------------
- "needs Far Cry patch 1.4" — обнови игру до 1.4.
- Игра запустилась, но ничего не происходит — открой log.txt и найди строки "[coop] FarCryCoop CryGame.dll
  loaded" и "[coop] launch request". Если первой нет — мод не загрузился.
- Вылет при запуске — удали папку Mods\FarCryCoop (игра вернётся к обычной), пришли конец log.txt.
- "Wrong Mod" при подключении — клиент запущен без мода; запускай через FarCryCoop.exe.
- Не подключается — дождись загрузки уровня у хоста, проверь брандмауэр (UDP 49001).
- Игры не находятся в локальной сети — хост должен быть запущен через FarCryCoop.exe, UDP 49099 не должен
  блокироваться. Можно просто ввести IP.
- Логи: FarCryCoop.log рядом с лаунчером и log.txt в папке Far Cry.

Неофициальный мод. Не связан с Crytek или Ubisoft. Far Cry — товарный знак Ubisoft, CryENGINE — Crytek.
CryGame.dll распространяется по лицензии CryENGINE MOD SDK (EULA.txt): бесплатно, только для полной версии игры.
